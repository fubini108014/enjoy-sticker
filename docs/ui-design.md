# 貼紙工作桌介面設計

以 frontend-design skill 與 PRD 為基礎，採用「數位貼紙工作桌」：讓使用者進入頁面就能開始拼貼，主要視覺來自真實可操作的 A4 紙面與貼紙。

## 設計 tokens

| 顏色 | 值 | 用途 |
| --- | --- | --- |
| 冷白 | #F5F8FC | 頁面背景 |
| 墨藍 | #23394B | 主要文字 |
| 鈷藍 | #315BE7 | 操作與選取狀態 |
| 薄荷 | #C9EADB | 貼紙與材質樣本 |
| 粉紅 | #FFB9D2 | 貼紙素材 |
| 晴黃 | #FFDA72 | 品牌小星與貼紙 |

Noto Sans TC 用於中文操作與說明，Outfit 用於品牌與數字。標題、區域標題、操作與輔助文字有明確層級；正文與控制項左對齊。

```text
品牌 / 工作桌 / 指南                              儲存草稿
標題與說明                                       製作流程
素材上傳與素材庫 | A4 紙面與操作列 | 選取貼紙與訂製設定
```

桌面採三欄工作桌；平板將設定移至畫布下方；手機依素材、畫布、設定順序排列。貼紙本身是視覺焦點，周圍面板保持安靜，不加入自動播放動畫。操作以明確動詞命名，保留鍵盤 focus 與 reduced-motion 支援。

## 設計檢視

以直接可編輯的紙面取代一般行銷首頁的大圖，符合使用者上傳與排版的主要目的。鈷藍用於操作，粉彩只用於貼紙素材與材質樣本；面板共用同一個工作桌容器，不將內容切成大量重複卡片。步驟數字只用於實際的設計、確認與收貨流程。

示範素材由程式內 SVG 繪製，無需外部素材圖庫。

## 功能與限制

- 支援 JPG、PNG、WebP，單檔 25 MB，最多 40 個畫布素材。
- 貼紙可拖曳，選取後用方向鍵微調；尺寸以 mm 設定。
- 白邊為瀏覽器影像陰影預覽，非幾何刀模。
- 自動排版使用矩形逐列排版，保留 3 mm 間距，非輪廓緊密排列演算法。
- DPI 依來源圖片寬度與設定物理寬度計算；向量示範素材另行標示。
- 草稿存於本機瀏覽器，儲存空間不足時提示；不是雲端存檔。
- 確認視窗為介面預覽，不會建立訂單或收款。
- 正式產品將依 PRD 使用 Next.js / Fabric.js 與後端 Worker 實作；本版為不需套件的設計原型。

## 畫布直接縮放與旋轉

選取貼紙後顯示四個角落的等比例縮放控制點，以及上方旋轉把手。縮放以對角作固定點、保持寬高比例；旋轉以圖案中心計算，Shift 拖曳以 15° 刻度調整。操作中顯示尺寸與角度，側欄即時同步，單次拖曳只記一個復原步驟；取消手勢還原初始狀態。控制點可用方向鍵微調，觸控裝置放大操作區。操作後重新執行印製檢查與自動存稿。

已實際拖曳縮放（49 → 60.1 mm）與旋轉（−11 → 80°），確認側欄同步；鍵盤控制點與復原亦已驗證。

## 新手體驗與效能更新

最新原型改為「上傳照片 → 確認效果 → 確認訂製」，第一步提供空白畫布與主動試用示範圖案。預設自動排版，常用尺寸按鈕直接調整；只有開啟自由排版才顯示畫布控制點。數值、角度與白邊收進進階設定。手機的大小、份數與背景工具各自開啟底部面板，固定底部保留商品小計與訂製入口。確認頁可調整材質、A4 張數與配送方式。

IndexedDB 保存圖片 Blob，草稿、示範訂單與復原紀錄引用圖片 ID；上傳原檔與最長邊 1200 px 的預覽分開保存。畫布重用 DOM 節點並避免重複設定未變更的圖案位置。工坊由獨立網址入口開啟；真實帳號權限仍待後端實作。性能目標、使用者測試與商業服務缺口詳見 PRD 第 14 章，不能以原型測試代表正式商業驗收。
本輪操作驗證：空白起始與主動載入三個示範圖案；尺寸快捷、自動排版、自由縮放與復原；確認頁 2 張 A4 搭配郵局運費顯示 NT$440；示範訂單與圖片重整恢復；上傳 JPG 的 WebP 預覽最長邊為 1200 px，恢復後來源 DPI 提示仍維持 754；390 px 手機工具面板與底部訂製入口可操作，沒有水平溢出。JavaScript 語法檢查通過。快照下載已改為內嵌圖片，但此輪瀏覽器工具未捕捉到下載完成事件，下載檔案仍需另行驗證。未測真實付款、裁切輸出與跨裝置性能。

## 畫布操作可見性更新

圖片選取後在畫布顯示複製／刪除快捷工具；按鈕位於圖案元素之外，避免隨圖片旋轉或被拖曳事件攔截。顧客可直接在畫布操作並復原，不必先找側欄。模式以「自動排版／自由編輯」並列切換，搭配藍色選取狀態及持續的鎖定／可拖曳提示；切換不重新安排已編輯位置。

畫布改為獨立捲動的編輯視窗，比例範圍 50–300%，提供適合視窗與 Ctrl／Command 滾輪縮放。顯示比例不影響 mm 尺寸；縮放改變紙張的實際顯示寬度，讓原有拖曳與控制點繼續使用相同的毫米轉換。快捷操作維持固定觸控大小，放大與捲動後仍可操作。

快捷工具採獨立圖示按鈕：重疊方框表示複製，垃圾桶表示刪除，刪除使用低彩度紅色；不顯示文字，保留 title 提示與螢幕閱讀器名稱，點擊目標為 44 × 44 px。縮放時優先聚焦目前選取的圖案。

本輪驗證：圖示複製 3 → 4 張、刪除 4 → 3 張，兩者可復原；200% 放大後可實際拖曳，毫米寬度仍為 50；控制點鍵盤縮放 50 → 51 mm 可復原；切換自動排版後顯示鎖定提示並保留位置；390 px 手機放大時只讓畫布橫向捲動，整頁沒有水平溢出；瀏覽器沒有 JavaScript error。

模式行為修正：預設自由編輯，包含恢復舊草稿時；自由編輯在左、自動排版在右，目前選取的模式都有 active 背景，只有一個模式能同時啟用。自動排版選項立即執行排列，已在此模式再次點選也會重新排列；排不下保留原位置與模式並提示。排列造成的位置變更可復原，切回自由編輯保留結果。已操作先移動 1 mm 再點自動排版，確認位置回到排列座標且 50 mm 寬度不變，復原有效。

模式與縮放整合為同一列工具列，模式在左、畫布比例與適合視窗在右。手機以比例選單取代加減按鈕，適合視窗改為圖示，保留 44 px 操作高度；模式說明仍保留給螢幕閱讀器，畫布下方顯示可拖曳／鎖定提示。已確認 390 px 下四個主要控制項同列、整頁無水平溢出，模式切換、比例選擇與適合視窗均可操作。
